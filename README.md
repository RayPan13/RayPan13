## 做過的事 Selected Work

### 前端標準化：專案樣板系統與工程規範 ・ 2018 – 至今

面對高頻率、同質性高的專案交付，把重複的部分收斂成可沿用的標準，讓每個新專案的工時集中在真正需要客製的地方。

- 盤點三個平台與歷年活動專案的共同需求，收斂為一套共用樣板與 SCSS 模組
- 建立標準化的專案初始化流程：依專案類型預先配置套件組合、Linter 規範與目錄結構，新專案直接沿用
- 設計廣告素材範本系統，將易出錯的手動配置改為規格化流程
- 制定前端開發規範（程式碼風格、目錄結構、模組使用與擴充原則），並撰寫文件供團隊依循
- 建立 Code Review 流程並實際擔任審查者；導入 Git Flow 分支策略與 CI/CD 自動化建置部署
- 團隊 4 人共用同一套標準與工具鏈

### 數位產品平台前端架構 ・ 2017 – 至今

同時維運三個產品線的前端：內容平台、電商平台、線上課程平台。

- 主導三個平台的前端架構設計與核心模組開發
- 執行架構重構，重整程式碼結構與資源載入策略
- 建立三平台一致的響應式實作標準，涵蓋桌機、平板、行動裝置
- 依 Lighthouse 稽核結果進行效能優化（圖片格式與尺寸、資源載入順序、第三方腳本延後載入），Performance 分數提升約 40%（專案估算）

產品連結：[內容平台](https://www.marieclaire.com.tw/) ・ [電商平台](https://magazine.marieclaire.com.tw/) ・ [線上課程平台](https://class.marieclaire.com.tw/)

### 高頻活動專案交付 ・ 2018 – 至今

活動型專案的交付節奏長期維持在每月兩個左右，每個需在數週內完成從設計稿到上線的完整前端實作，包含互動模組、Canvas 小遊戲與 API 串接。

- 以前述樣板系統與一鍵部署流程支撐此交付節奏
- 每個專案的開發重心得以集中在客製化互動與視覺，而非重複的環境與設定工作

- 實作排程執行、資料清洗、輸出格式標準化與錯誤通報

### 數據追蹤與 SEO 架構

- 設計 GA4 事件追蹤方案與數據儀表板，作為產品與營運決策依據
